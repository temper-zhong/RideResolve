# Submission eligibility evidence

Place only manually reviewed CodeBuddy or WorkBuddy development screenshots here.

Final-package requirements:

- at least three PNG or JPG screenshots, or one qualifying screen recording;
- product name, development request, and substantive AI assistance are readable;
- API keys, role tokens, deployment credentials, personal identifiers, local paths, workspace IDs, run/request/trace IDs, container names, and pod names are removed or masked;
- Tencent ADP screenshots are not used as a substitute for CodeBuddy/WorkBuddy proof.

This directory currently contains instructions only, so the final submission package is blocked. A candidate package may still be built for local inspection.
